# 西电数学建模资料归档

Last reviewed: 2026-09-13

## Product Intent

收集、保留并持续更新西安电子科技大学数学建模相关的公开原始资料，让参赛者能从一个结构稳定的 GitHub 仓库取得规则、格式、通知、培训材料与优秀论文，而不必依赖会失效的网页入口。

## Audience And Primary Experience

- Primary audience: 西电数学建模参赛学生、指导教师和资料维护者。
- Primary need: 获得可验证来源、可直接下载的官方与公开原始材料。
- Primary end-to-end experience: 按来源/赛事/年份进入目录，直接读取原文件；需要上下文时通过来源索引回到原网页。
- Intended emotional or practical outcome: 快速、可信地定位比赛所需的原始资料。

## Product Boundaries

### In Scope

- 官方赛事规则、竞赛章程、论文格式、通知与公开附件。
- 西电官方、数学建模协会及公开学生分享中的原始资料与原始链接。
- PDF、PPT/PPTX、DOC/DOCX、XLS/XLSX、压缩包等可公开直接获取的附件，保留原文件名或使用清晰中文名。
- 简单的来源/赛事/年份目录与网页原始链接索引。

### Non-Goals

- 教程、学习路线、知识总结、题目讲解与 AI 生成内容。
- 对原始材料的改写、摘编或结论性评价。
- 未授权转载、付费或需要登录才能取得的资料。

## System Map

- 原始附件归档：以来源、赛事、年份存放直接下载文件。
- 来源可追溯性：每一类公开网页保留原始 URL。
- 仓库卫生：文件名、目录和 Git 追踪状态保持稳定；不混入生成式教程。

## Quality Bar

- 下载文件必须与官方/原作者公开直链一致；来源链接必须能回溯。
- 资料不经二次改写，附件优先原始文件名。
- 目录层级保持为来源/赛事/年份，避免深层分类。

## Definition Of Done

The product is complete only when every condition below has inspectable evidence:

- 每个已收录文件均可打开，并有可追溯来源。
- 索引覆盖西电官方、数学建模协会、CUMCM、COMAP 和公开学生分享的可访问入口。
- CUMCM 规则、论文格式、竞赛章程等确定可下载的核心 PDF 已归档。
- 不存在教程、学习路线、AI 说明或其他无关生成内容。
- 发布前完成 Git 状态和资料清单核对。
