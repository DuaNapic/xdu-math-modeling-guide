# 西电数学建模资料归档 Roadmap

Last reviewed: 2026-09-13

## Allocation Policy

- Close regressions and shared blockers first.
- Raise lagging must-have systems to the active phase floor before optional expansion.
- Prefer complete vertical slices over disconnected scaffolding.
- Record and time-bound any deliberate imbalance exception in `STATE.json`.
- Reserve explicit integration, stabilization, accessibility, performance, packaging, and release work as applicable.

## P0: Product Contract

Objective: establish product intent, system boundaries, requirements, risks, maturity targets, and completion criteria.

Exit criteria:

- All must-have systems and dependencies are mapped.
- Requirements that would change architecture or product scope are resolved.
- The product-level definition of done is measurable.

## P1: Core Source Coverage

Objective: establish the requested official and public-source directory structure, source index, and directly downloadable core files.

Exit criteria:

- The source index covers the named Xidian, CUMCM, COMAP, association, and public sharing pages.
- Every confirmed direct-download core CUMCM PDF is stored as an original file.
- The repository has no tutorial or rewritten educational content.

## P2: Ongoing Collection

Objective: add newly discoverable public notices, training files, excellent papers, and historical materials without weakening provenance.

Exit criteria:

- New files are placed by source/event/year and verified to open.
- Every new source page is recorded in the source index.

## Deferred Scope

- Derivative tutorials, learning plans, AI usage explanations, and analysis of the source material are intentionally excluded.
